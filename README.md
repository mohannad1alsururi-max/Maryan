# موسوعة ماريان | ذاكرة اليمن الحيّة

واجهة عربية RTL بتصميم كحلي وذهبي، وتجربة متجاوبة للجوال والحاسوب.

## الموجود حاليًا
- واجهة رئيسية حديثة وتأثير ripple خفيف مع دعم prefers-reduced-motion.
- مكتبة نموذجية مع بحث وتصنيفات محلية.
- قارئ معاينة داخلي لثلاث صفحات نصية نموذجية.
- رسم تخطيطي تفاعلي للمحافظات وبطاقات تعريف أولية.
- واجهة محادثة تجريبية توضح صراحة أن خدمة الذكاء الاصطناعي غير موصولة.
- لا توجد مفاتيح سرية داخل الواجهة.

## الحالة المهمة
هذه نسخة واجهة ثابتة أولية، وليست بعد منصة إنتاج متصلة بالخدمات. لم يتم تفعيل أو اختبار Supabase Auth/RLS، رفع PDF، استخراج النص وOCR، فهرسة المصادر، الذكاء الاصطناعي، قارئ PDF حقيقي، أو خريطة Google ثلاثية الأبعاد. الخريطة الحالية رسم توضيحي وليست حدودًا جغرافية دقيقة. لا تعتبر نموذج الإدارة أو البريد وحده وسيلة حماية.

## النشر التجريبي
افتح `index.html` محليًا، أو من GitHub اختر Settings → Pages → Deploy from a branch → main → /(root).

## الخطوات الإنتاجية التالية
1. إضافة تطبيق TypeScript مع اختبارات lint/build.
2. إعداد Supabase Auth وRLS وجداول الكتب ومقاطع المعرفة ومصادرها.
3. تقييد الإدارة بالتحقق الخادمي من هوية المالك، مع سياسات تخزين خاصة.
4. رفع PDF آمن، واستخراج metadata والنص/OCR وفهرسته مع أرقام الصفحات ومصادر موثقة.
5. ربط قارئ PDF فعلي يدعم التحميل التدريجي وحفظ موضع القراءة.
6. إنشاء endpoint AI خادمي مع استرجاع معرفي وإحالات للمصادر وقصر النطاق على اليمن.
7. دمج مزود خرائط مرخص وبيانات GIS دقيقة؛ توفر 3D ومستوى التفاصيل يختلفان حسب المنطقة والمزود.
8. إضافة اختبارات أمان ووصولية وE2E، مراقبة الأخطاء ونسخ احتياطي وسياسة خصوصية وحقوق نشر.

لا تضع API keys في الواجهة الأمامية. أضف الأسرار عبر إعدادات الخادم فقط.
